# Python 長袖 DXF GUI

`sleeve_gui.py` 是獨立的 Python/Tkinter 介面，不會改變原本的
LibreCAD Sleeve Analyzer 插件。它可以讀取含有閉合袖片的 DXF，依檔名辨識尺寸，
選擇同尺寸的不同袖長款式，另存新的長袖 DXF。尺寸資料路徑保存在目前 Windows
使用者的登錄檔：
`HKEY_CURRENT_USER\Software\LibreCAD\SleeveAnalyzer`，值名稱為 `SizeDataPath`。
第一次啟動時會使用腳本旁的 `plugins/sleeveanalyzer/sleeve_sizes.json` 並登錄該路徑。

## GUI 啟動

在 `tools` 目錄執行：

```powershell
python .\sleeve_gui.py
```

GUI 欄位均使用 mm：

- `袖子 DXF`：選擇輸入檔，支援 classic `POLYLINE` 與 `LWPOLYLINE`。
- 若已安裝 `tkinterdnd2`，也可以直接從 Windows 檔案總管把單一 `.dxf` 檔案拖到 GUI 視窗，程式會自動填入來源檔案與預設輸出檔名。
- `輸出 DXF`：選擇新檔案位置。
- `袖長`：長袖實際尺寸內框的袖軸跨度，例如 `627`。
- `袖口寬`：袖口寬度，例如 `225.17`。
- `縫份`：裁切外框外擴量，預設 `7.9375` mm，與原功能的 fallback 相同。
- `袖口折口距離`：裁片線至折口的距離，預設 `19.05` mm（0.75 英吋）。
- `鏡射接合`：勾選時只鏡射裁切外框的上、下側線，以內框袖口中心線為軸，在上下兩處接回原外框；袖山外曲線不鏡射，最後形成如青線的一條閉合外框。`LONG_SLEEVE_SEAM` 內框維持原樣。袖口折口距離控制袖口裁切邊位置。預設不勾選。
- `選擇尺寸檔`：挑選有效的尺寸 JSON。載入成功後會切換目前尺寸資料，並更新上述登錄值；重新啟動時會載入該檔案。
- `重新載入`：重新讀取登錄值指向的 JSON。管理尺寸或款式後，儲存會寫回目前選取的 JSON。

## 資料夾批次轉換

切換到 `資料夾批次轉換` 分頁後：

1. 選擇含有尺寸資料的 `.xlsx` 或 `.xlsm` 檔案。畫面會列出尺寸、袖長、袖口平量及換算後袖口寬；袖長與袖口欄可讀取 mm 欄，若 Excel 公式沒有快取值則會以 cm 欄乘 10 換算。
2. 選擇來源 DXF 資料夾，設定 `批次名稱`，再設定 `延伸名稱`（預設 `長袖`）。程式會在來源資料夾下建立批次名稱子資料夾；輸出檔名格式為 `原檔名_,延伸名稱.原附檔名`，例如 `XS-S0620A-袖X2_,長袖.dxf`。
3. `批次名稱` 會同時作為 JSON 款式名稱與輸出子資料夾名稱。按 `合併寫入單件尺寸 JSON`，會在每個尺寸的 `variants` 下新增或更新同名款式，寫入 Excel 袖長與「袖口寬平量 × 2」；現有的 `standard`、short／long 款及預設款設定都會保留。找不到的尺寸會新增，並以批次名稱作為該尺寸的唯一款式。儲存前會建立 `.bak` 備份。
4. `刪除合併款式` 會從目前尺寸 JSON 移除批次名稱相同的款式；若尺寸只剩這一款，會一併刪除該尺寸記錄。刪除前會顯示筆數並要求確認，已產生的 DXF 不會刪除。
5. 按 `批次產生長袖 DXF` 開始轉換。程式只處理所選資料夾第一層的 `.dxf`，由檔名的獨立 token 辨識尺寸；找不到尺寸、檔名含多個尺寸或輸出檔已存在時會略過並記錄原因，不會覆蓋既有檔案。

批次轉換會使用所選 Excel 的袖長與袖口數值。批次分頁有 `鏡射接合` 勾選框，與 `單件轉換` 分頁共用同一設定；勾選時批次輸出會使用鏡射接合外框。縫份及袖口折口距離沿用 `單件轉換` 分頁的值。

左側預覽區會依照 Plugins 內 Sleeve Analyzer 的分析資料顯示原始袖片、袖山、
P1/P2/P3、袖軸、原袖口、目標袖口、長袖上下側線，以及目前設定生成的裁切外框；
不論是否勾選「鏡射接合」，預覽都會顯示外框，勾選時只改變外框的鏡射接合形狀。
選擇或拖入來源 DXF 後，
程式只會從檔名的獨立 token 辨識尺寸；無法辨識或有多尺寸衝突時會清除目前選擇，
要求手動選取，不會沿用前一個檔案的尺寸。修改尺寸欄位只影響本次預覽/輸出，畫面會
標示「未存入尺寸表」；可用「儲存至目前款式」或「另存新款式」明確寫入。

「管理尺寸」視窗支援尺寸與款式的新增、複製、改名、刪除、設為預設及數值編輯。
它在暫存副本上工作，按「取消」不落盤；儲存會先驗證、建立同目錄的 `.json.bak`
備份，再用暫存檔原子替換。若 JSON 遺失、損壞或被其他程式
修改，會顯示完整路徑與原因，不會用空資料覆蓋。舊款式的 `cuff_width_mm: 0` 會在
執行時回退到同尺寸 `standard` 的正值，讀取時不會偷偷改寫 JSON。

輸出只建立新的長袖裁片，不會把原始短袖一起輸出，並建立兩個圖層：

- `LONG_SLEEVE_SEAM`：長袖實際尺寸內框。
- `LONG_SLEEVE_CUT`：縫份裁切外框，袖山外框沿用輸入袖片的原始牙口細節。

## 命令列模式

```powershell
python .\sleeve_gui.py input.dxf output_long_sleeve.dxf `
  --sleeve-length 627 --cuff-width 225.17 --cuff-fold-distance 19.05
```

預設不輸出原始短袖；若需要診斷用的原始袖片，可額外加入
`--include-source`。

若要啟用拖放功能，可安裝選用套件：

```powershell
python -m pip install tkinterdnd2
```
